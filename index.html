    How it works

    A zero-dependency binary PDF parser running entirely inside your browser's memory.

    1

    Binary Byte Scanning

    LeakyPDF reads the file via the browser File API, locates all %%EOF markers, cross-reference tables, and indirect obj ... endobj records directly from raw bytes.

    2

    Stream Decompression

    Compressed object streams (/Type /ObjStm), XMP XML packets, and embedded attachments compressed with /FlateDecode are unpacked locally using the native Web Streams DecompressionStream API.

    3

    Forensic Risk Audit

    Every dictionary is evaluated for privacy leaks, incremental revision snapshots are carved for inspection, and an exportable Markdown or JSON report is generated offline.

    Frequently Asked Questions

    Are my PDF files uploaded to any server?

    No. LeakyPDF is a single static HTML file with zero external network requests. All byte parsing, deflate decompression, and revision extraction run locally inside your browser tab. You can disconnect from the internet after loading the page and it will work identically.

    Why do incremental updates keep earlier versions of a PDF recoverable?

    When you click "Save" (rather than "Save As") in many PDF editors, the software appends changed objects and a new cross-reference table after the existing %%EOF marker instead of rewriting the file. Truncating the file at an earlier %%EOF lets anyone open the document as it existed before those edits.

    What is the difference between a black rectangle and an applied redaction?

    Drawing a black shape or placing a redaction mark (/Subtype /Redact) in a PDF editor only adds an annotation layer on top of the page. Until you click "Apply Redactions" to permanently strip the underlying text operators, the sensitive words remain selectable and extractable in the page stream.

    How do I permanently strip hidden metadata, comments, and old versions from a PDF?

    Use your PDF editor's dedicated sanitization tool (such as "Sanitize Document" or "Remove Hidden Information" in Adobe Acrobat) and save a fresh copy. Alternatively, printing the PDF to a new PDF or rasterizing sensitive pages flattens layers, removes incremental history, and discards annotations—though you should always re-check the output file with LeakyPDF afterward.

    What happens if I scan an encrypted or password-protected PDF?

    If a PDF uses standard encryption (/Encrypt dictionary present), its object streams and strings are cryptographically scrambled. LeakyPDF detects and reports the encryption parameters, version, and revision count, and notes that encrypted internal objects cannot be inspected without first decrypting the document.

    Does LeakyPDF inspect text hidden under opaque black vector rectangles?

    LeakyPDF specifically detects unapplied /Redact annotations, annotation overlays, and earlier incremental revisions. Because black vector rectangles drawn without redaction annotations require full page content-stream graphics state rendering, you should always visually test redactions by trying to select and copy text across redacted areas in addition to running LeakyPDF.
